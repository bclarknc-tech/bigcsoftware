BIGCS toolbar and menu

The installer loads the BIGCS toolbar for you. To load it by hand, type APPLOAD in Carlson or AutoCAD and load
BIGCS_menu.lsp from the cad folder of your BIGCS install folder
(default: %LOCALAPPDATA%\Programs\BIGCS\app\cad\BIGCS_menu.lsp).
