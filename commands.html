Commands

Command list

BCS commands, with the original G2C and GIS2CAD names still working. Each object records which GIS source it came from and when it was pulled. Runs in Carlson, IntelliCAD and full AutoCAD.

CommandAlso works asWhat it does
BCSG2C, GIS2CADInsert parcels: boundary + owner/deed/plat labels. Locate by Pick, Lat/Lon, State Plane N/E, Address or PIN; mode Single, Adjoiners, Radius or Window.
BCSTXTG2CTXT, GIS2CADTXTSame as BCS but labels only, no parcel boundary.
BCSADJG2CADJ, GIS2CADADJAdjoiner table placed in the drawing, plus a CSV saved beside the drawing.
BCSREFG2CREF, GIS2CADREFRefresh every BIGCS label from county GIS by its stored PIN; updates text and date stamp and saves a CSV of changes.
BCSLTRG2CLTR, GIS2CADLTROpen BIGCS Letters (separate window) using the drawing's adjoiner CSV.
BCSMAPBCSBND, G2CBND, GIS2CADBOUNDSMap Layers window (formerly Boundaries): state/county borders, NGS and state monuments, road centerlines, easements/ROW and flood zones, by county or a picked area. Includes Draw Building Footprints (Beta).
BCSBLDGBuilding footprints (Beta, NC only): Window or Parcel (50 ft buffer by default). Draws closed polylines on layer BIGCS-BLDG; set layer, color and linetype in BCSST.
BCSSTG2CST, GIS2CADSTYLELabel style editor: line order, wording, fonts, justification, layers, live preview.
BCSLOADG2CLOAD, GIS2CADLOADLoad an already-generated BIGCS result file (.lsp), e.g. from a batch run.
