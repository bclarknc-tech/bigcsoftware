County coverage

What BIGCS can bring into your drawing, county by county. ✓ = available, Partial = available for some parcels or part of the county, – = not available. Where a county's data comes from an older copy, it is labeled next to the county name.

Data comes as-is from each county's public GIS. BIGCS never adjusts or datum-shifts it. Coverage changes as counties update their systems. This list is preliminary and is still being reviewed.

Coverage varies by county, and we are adding fields as sources become available. A check mark means that item works for that county today. No check mark means it is not available there yet. Check your county below before you buy.

Currently available states (28): NC, SC, VA, TN, AR, AZ, CT, DC, DE, FL, IL, MA, MD, MN, MO, MS, MT, ND, NJ, NV, NY, OH, PA, SD, TX, VT, WI, WV.

Key
  • State Control = control published by a state agency (e.g. NC Geodetic Survey)
  • NGS Control = National Geodetic Survey marks
  • Partial = some data available
  • Buildings = building footprints can be drawn in all 28 states BIGCS covers today. No check mark means no building footprint source for that county yet.
  • Source = the parcel data source is named for every county (“None found” where no public source was found)
  • Older copy = data is from an archived copy, not the county's live server

No counties match.

Owner names come from each county's public GIS records. Most print cleanly, but some counties publish names that are abbreviated, cut off or out of order, and those print the way the county stores them. Always confirm owner names with the official records.
