Install help

Windows shows "Windows protected your PC" when I run the installer

This is normal for new software. Windows SmartScreen shows this message for installers from a publisher it has not seen many downloads from yet. BIGCS is new, so it has not built up that reputation. The message does not mean anything is wrong with the file.

To continue the install:

  1. On the blue "Windows protected your PC" screen, click More info.
  2. Click Run anyway.
  3. Follow the installer as usual.

Check your download (optional)

If you want to confirm the file is the one we published, compare its SHA-256 checksum to the checksum file (BIGCS_1.1_Setup.exe.sha256) on the download page. In PowerShell, run:

Get-FileHash "C:\path\to\BIGCS_1.1_Setup.exe" -Algorithm SHA256

The value it prints should match the one in the checksum file exactly. If it does not, do not run the installer. Download it again, or email us.
